# Moto Naranja — лендінг оренди мопедів у Валенсії

Статичний односторінковий сайт без збірки та фреймворків: HTML + CSS + трохи ванільного JS.
Дві мовні версії: англійська (`index.html`, для туристів) і українська (`uk/index.html`).
Дизайн: «вінтажна етикетка валенсійських апельсинів» — кремовий папір, помаранчевий, чорнильно-синій,
жорсткі тіні; шрифти Fraunces, Figtree, DM Mono (Google Fonts).

## Структура

| Файл | Що всередині |
| --- | --- |
| `index.html` | англійська версія: hero, флот, ціни, як це працює, маршрути з картою, FAQ, форма бронювання |
| `uk/index.html` | українська версія з тією самою структурою та розміткою |
| `assets/css/styles.css` | стилі; кольори та шрифти винесені в змінні у `:root` |
| `assets/js/main.js` | мобільне меню, анімації появи, FAQ, розрахунок ціни у формі та відправка запиту в WhatsApp; тексти для обох мов у об'єкті `I18N` |
| `favicon.svg` | іконка сайту |

## Мови

- Перемикач EN / UA у шапці та футері, `hreflang` у `<head>` обох сторінок.
- Скрипт визначає мову з атрибута `<html lang>` і бере відповідні тексти (повідомлення у WhatsApp, розрахунок днів, підказки форми).
- Fraunces, Figtree і DM Mono не мають кирилиці, тому для української сторінки в CSS (`:root:lang(uk)`) додано фолбеки з кирилицею: Vollkorn, Onest, IBM Plex Mono. Латиниця, цифри та назва бренду лишаються в основних шрифтах.
- Обидві сторінки — окремі файли: зміни в контенті треба вносити в обидві.

## Запуск локально

Достатньо відкрити `index.html` у браузері. Або з локальним сервером:

```bash
python3 -m http.server 8080
# http://localhost:8080  та  http://localhost:8080/uk/
```

## Що замінити перед запуском

Увесь контент — плейсхолдер, який треба замінити на реальні дані (в обох мовних версіях):

- **Назва бренду** `Moto Naranja` — title, meta, логотип у шапці та футері, JSON-LD; тексти повідомлень в `assets/js/main.js`.
- **Номер WhatsApp** `34600000000` — посилання `wa.me` (hero, контакти, плаваюча кнопка) і константа `WA_NUMBER` у `assets/js/main.js`.
- **Email** `hola@motonaranja.com` — сторінки та константа `EMAIL` у `assets/js/main.js`.
- **Адреса та години роботи** — секція «Book» / «Бронювання» і JSON-LD.
- **Ціни, депозити, моделі** — картки флоту, таблиця цін, варіанти в `<select>` форми та об'єкт `RATES` у `assets/js/main.js` (мають збігатися між собою).
- **Домен** `motonaranja.com` — `canonical`, `hreflang`, `og:url`.
- **Посилання Privacy / Terms / Legal notice** у футері (зараз ведуть на `#`).
- **Умови** (мінімальний вік, права, страховка, скасування) у FAQ — перевірити з реальною політикою компанії.

Швидка заміна номера в усіх файлах:

```bash
grep -rl 34600000000 index.html uk assets | xargs sed -i 's/34600000000/34XXXXXXXXX/g'
```

## Деплой

Збірка не потрібна. Варіанти:

- **GitHub Pages**: Settings → Pages → Deploy from a branch → `main` / `(root)`. Українська версія буде за адресою `/uk/`.
- Netlify, Cloudflare Pages, Vercel — як статичний сайт з коренем репозиторію.

## Далі

- Іспанська версія: копія `index.html` у `es/index.html` за тим самим принципом.
- Реальні фото флоту замість SVG-ілюстрацій (ілюстрації можна залишити як стиль бренду).
- Онлайн-бронювання з оплатою, коли лендінг перестане бути «суто лендінгом».
