# Moto Naranja — лендінг оренди мопедів у Валенсії

Статичний односторінковий сайт без збірки та фреймворків: `index.html` + CSS + трохи ванільного JS.
Мова сайту — англійська (цільова аудиторія — туристи). Дизайн: «вінтажна етикетка валенсійських
апельсинів» — кремовий папір, помаранчевий, чорнильно-синій, жорсткі тіні; шрифти Fraunces, Figtree, DM Mono
(Google Fonts).

## Структура

| Файл | Що всередині |
| --- | --- |
| `index.html` | уся розмітка й контент: hero, флот, ціни, як це працює, маршрути з картою, FAQ, форма бронювання |
| `assets/css/styles.css` | стилі; кольори та шрифти винесені в змінні у `:root` |
| `assets/js/main.js` | мобільне меню, анімації появи, FAQ, розрахунок ціни у формі та відправка запиту в WhatsApp |
| `favicon.svg` | іконка сайту |

## Запуск локально

Достатньо відкрити `index.html` у браузері. Або з локальним сервером:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Що замінити перед запуском

Увесь контент — плейсхолдер, який треба замінити на реальні дані:

- **Назва бренду** `Moto Naranja` — `index.html` (title, meta, логотип у шапці та футері, JSON-LD) і текст повідомлення в `assets/js/main.js`.
- **Номер WhatsApp** `34600000000` — посилання `wa.me` в `index.html` (hero, контакти, плаваюча кнопка) і константа `WA_NUMBER` у `assets/js/main.js`.
- **Email** `hola@motonaranja.com` — `index.html` і константа `EMAIL` у `assets/js/main.js`.
- **Адреса та години роботи** — секція «Book» і JSON-LD у `index.html`.
- **Ціни, депозити, моделі** — картки в секції «Fleet», таблиця в «Prices», варіанти в `<select>` форми та об'єкт `RATES` у `assets/js/main.js` (мають збігатися між собою).
- **Домен** `motonaranja.com` — `canonical` та `og:url`.
- **Посилання Privacy / Terms / Legal notice** у футері (зараз ведуть на `#`).
- **Умови** (мінімальний вік, права, страховка, скасування) у FAQ — перевірити з реальною політикою компанії.

Швидка заміна номера в усіх файлах:

```bash
grep -rl 34600000000 index.html assets | xargs sed -i 's/34600000000/34XXXXXXXXX/g'
```

## Деплой

Збірка не потрібна. Варіанти:

- **GitHub Pages**: Settings → Pages → Deploy from a branch → `main` / `(root)`.
- Netlify, Cloudflare Pages, Vercel — як статичний сайт з коренем репозиторію.
